## Project Info

- **Stack:** Next.js 15 (App Router, server components) + React 19, plain CSS tokens (project lives in `store/`)
- **Backend / database:** Next.js server code + Postgres on Neon via `pg` (`store/lib/db.js`, `DATABASE_URL`; schema in `store/schema.sql`, applied with `npm run migrate`). Images are stored on Cloudinary (`store/lib/uploads.js`, `CLOUDINARY_URL`); the database keeps their https URLs
- **Auth:** own sessions, no library. `lib/auth.js` (scrypt hashing, validation, throttle, session cookie `hs_session`), one route `app/api/auth/[action]/route.js` (signin / signup / signout), screens in `components/AuthPage.js`. `getDeveloper()` returns the signed-in developer or `null`; Tasks 15-19 build on it
- **CSS load order:** tokens.css, base.css, brand.css, components.css (all in `store/public/`, linked from `app/layout.js`)
- **JS:** ui.js (menu toggle, filter auto-submit, icon fallback, toasts, uploads), plus a one-line `has-js` class snippet in `<head>`
- **UI reference:** [reference/ui-mockup.png](./reference/ui-mockup.png), notes in [reference/README.md](./reference/README.md) (layout guide; spec and tokens win on conflicts)
- **Code size target:** 1,800-2,600 lines of application code
- **Current line count:** 3,365 raw: 1,981 in `app/`, `components/`, `lib/` and `public/ui.js`, plus 1,384 in tokens, base, brand and components CSS. **Over the raw target**; the decision is Task 24 (see Risks). styleguide.html is dev-only and excluded.
